# Download

Installable Android APKs live here:

- **`oniLibrary-v1.1.1.apk`** — current release (see the
  [v1.1.1 release notes](https://github.com/onimeno62/oniLibrary_zai_2/releases/tag/v1.1.1))
- `oniLibrary-v1.1.1.apk.idsig` — apksigner signature file (only needed for incremental installs via some tools)

Sideload: copy to your phone, tap the file, allow "install unknown apps" when prompted.
Minimum Android 7.0 (API 24). Updates install over previous versions without losing data.

You can also build the APK yourself — see [`docs/BUILDING.md`](../docs/BUILDING.md).
